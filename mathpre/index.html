§ 02

Introduction

A network as a graph

A computer network connects devices such as computers, switches, routers and servers.

Devices communicate through wired or wireless connections.

Graph Theory represents devices as vertices and communication links as edges.

A spanning tree is a connected subgraph that includes all vertices without forming any cycles.

It helps design efficient networks by reducing unnecessary connections.

Useful in campus networks, office networks and communication systems.

§ 03

The Problem

A college has n buildings. Connect them all with cable. Every building must reach every other. Cable is expensive. No pointless loops.

  1. Networks contain many devices that must connect to communicate and share resources.
  2. Too many links increase installation and maintenance costs.
  3. Unnecessary connections can create cycles or loops.
  4. Every device must still be able to reach every other device.
  5. The challenge: find the required connections and avoid unnecessary links.
  6. A spanning tree connects all n devices using exactly n−1 links, with no cycles.

Minimum Spanning Tree

DEFINITION

A minimum spanning tree (MST) is a spanning tree whose total weight w(T) = ∑e ∈ T w(e) is as small as possible.

MATHEMATICAL FACTS
  • If all edge weights are distinct, the MST is unique.
  • If weights tie, multiple MSTs may exist, all with the same minimum total.

§ 10

Prim's Algorithm

Start at one vertex. Grow a single tree outward. Each time, take the cheapest edge that leaves the tree.

pick a start vertex s; tree = {s} put all edges leaving the tree into a min-heap repeat until tree has all n vertices: pop the cheapest edge (u,v) from the heap if v is already in the tree: skip it else: add v and edge (u,v) to the tree push every edge from v to a vertex outside the tree

Full Formal Proofs: Cut & Cycle Properties

Definitions

A cut is a split of the vertex set into S and V minus S (both non-empty). An edge crosses the cut if one endpoint is in S and the other is not.

Theorem 1 (Cut property, general form)

Let A be a set of edges contained in some MST T. Let (S, V\S) be a cut that no edge of A crosses. Let e be a lightest edge crossing the cut. Then A ∪ {e} is contained in some MST. If e is the strictly lightest crossing edge, e is in EVERY MST.

Proof of Theorem 1 (Setup & Unique Path)

If e is already in T we are done. Otherwise T has a unique path between the endpoints of e (they are in different sides of the cut), and that path must contain an edge f that crosses the cut. f is not in A, because no edge of A crosses the cut.

Proof of Theorem 1 (Edge Exchange & Tree Property)

Remove f from T and add e. The result T′ = T − f + e is connected with n−1 edges, so it is a spanning tree.

Proof of Theorem 1 (Minimality & QED)

w(T′) = w(T) − w(f) + w(e) ≤ w(T) because e is lightest crossing, w(e) ≤ w(f). So T′ is also an MST, and it contains A ∪ {e}. If w(e) < w(f) strictly, then w(T′) < w(T), contradicting that T is minimum, so every MST contains e. QED.

Theorem 2 (Cycle property)

If e is the unique heaviest edge on some cycle C of G, then no MST contains e.

Proof of Theorem 2 (Cycle Cut & Edge f)

Suppose an MST T contains e. Removing e from T splits T into two components. The rest of the cycle, C minus e, is a path joining the two endpoints of e, so it contains some edge f crossing between the two components.

Proof of Theorem 2 (Lighter Edge Contradiction)

w(f) < w(e). Then T − e + f is a spanning tree with smaller weight, contradicting minimality. QED.

Corollary 1 (Kruskal is correct — Accepted Edges)

Invariant: the accepted edges A are always contained in some MST. When Kruskal accepts e = (u,v), u and v are in different components. Let S = the component of u. No accepted edge crosses (S, V\S). Any lighter edge crossing this cut would have been examined earlier and accepted (its endpoints were in different components then, since components only grow and u,v are still apart). That is impossible, so e is a lightest crossing edge. By Theorem 1, A ∪ {e} is still inside some MST.

Corollary 1 (Kruskal is correct — Rejected Edges)

Rejected edges close a cycle in which they are the heaviest edge examined so far (all others are already accepted, so lighter or equal), so by Theorem 2 they are safe to discard (for distinct weights).

Corollary 2 (Prim is correct)

At each step let S = vertices in the tree. The tree edges A do not cross (S, V\S). Prim takes a lightest edge crossing the cut, so Theorem 1 keeps A inside some MST.

Both are fast. Which is faster depends on the graph.

Kruskal O(E log E)

Kruskal spends its time sorting the edges.

Prim (with heap) O(E log V)

Prim spends its time picking the cheapest edge from a heap.

Limitations

Single Points of Failure: No backup. A tree has exactly n−1 edges and every edge is a bridge: cut any one and the network splits in two.
Suboptimal Hop Detours: It minimises TOTAL cable, not the distance between two particular machines. A short trip in the network can become a long detour in the tree.

Spanning Tree Protocol Details

Key Facts

  • Bridge ID: priority (default 32768) + MAC address; lowest Bridge ID becomes the root bridge.
  • Every other switch keeps the one port with the lowest path cost to the root (root port).
  • Each link has one designated port (the end closer to the root). Everything else is blocked.
  • Switches exchange BPDUs (every 2 seconds by default).
  • Path cost examples: 10 Mbps = 100, 100 Mbps = 19, 1 Gbps = 4, 10 Gbps = 2.
  • Port states: blocking, listening, learning, forwarding.

§ 17

Conclusion

1

A network is a weighted graph: devices are vertices, cables are edges, and cable cost is the weight.

2

A tree is connected with no cycles, so n vertices use exactly n−1 edges. A spanning tree reaches every vertex, and the complete graph Kn has nn−2 of them.

3

The minimum spanning tree (MST) is the spanning tree with the smallest total weight.

4

Kruskal (sort edges, skip cycles) and Prim (grow from one vertex) both find it, because of the cut property.

5

Both run in about O(E log V). Prim with an adjacency matrix, O(V2), suits dense graphs.

6

An MST has no backup links and does not minimise distance between two machines. Fixes are backup links, shortest-path trees and Steiner trees. STP uses a spanning tree to stop loops in real networks.
