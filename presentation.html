Indoor Nav

An Indoor Navigation System for College Campuses

Scroll to explore

The Problem

🏫

Large campus buildings are confusing for new students, visitors, and staff

📍

No existing system provides room-level indoor navigation

📅

Events and activities inside buildings are hard to discover and locate

GPS doesn't work indoors. There's no Google Maps for buildings.

What We Built

Indoor Nav is a full-stack web application that lets administrators map any building floor-by-floor, add rooms, events, and navigation nodes — and lets users navigate room-to-room with turn-by-turn directions, all from a mobile browser.

Map Editor

editor.png Map Editor — Floor 1 view with nodes and edges
Intuitive Tile Painting: Draw paths and define spaces by selecting from 10+ intelligent tile types including Corridors, Toilets, Staircases, and Construction zones.
Semantic Room Labeling: Assign meaningful names, numbers, and descriptive metadata to any enclosed space so users can search for exact locations.
Precision Navigation Graph: Click to drop invisible navigation nodes at critical intersections and corners to build a robust pathfinding network.
Edge Connections: Visually link nodes together to define exactly where users are allowed to walk, preventing routes through solid walls.
Multi-Floor Architecture: Seamlessly switch between building levels (Ground, Floor 1, Floor 2) while maintaining global coordinate alignment.
Data Portability: Export entire building topologies as lightweight JSON files, and import them instantly for backups or deployment.

Routing & Navigation

A* Pathfinding Algorithm: The system utilizes the highly efficient A* search algorithm, guaranteeing the absolute shortest path between any two locations.
Continuous Graph Evaluation: The engine calculates distance metrics using the custom nodes and edges mapped by the administrator in real-time.
Dynamic Route Visualization: The computed optimal path is instantly painted onto the map canvas, adapting instantly if the user changes their destination.
Actionable Turn Instructions: Abstract path data is translated into human-readable steps like "Head straight," "Turn left," and "Arrive at destination."
navigation.png Navigation page — path highlighted with directions panel

Event Management

events.png Event Management page
Comprehensive Event Data: Administrators can schedule seminars, classes, and college fests with rich titles, descriptions, and precise time windows.
Spatial Anchoring: Every created event is tightly coupled to a specific room ID in the building's semantic topology.
Live User Visibility: The mobile interface automatically fetches and displays active events, keeping the campus community informed in real-time.
One-Tap Routing: Users exploring the event list can tap "Navigate Here" to instantly bypass manual search and route directly to the venue.

Navigate with QR

setup_route.png Setup Route screen showing QR tiles for each room
Location-Aware QR Codes: The system generates a distinct, printable QR code for the entrance of every registered room.
Instant Start Point: When a user scans a door's QR code, the web app launches with their exact physical location pre-filled as the starting node.
Frictionless Searching: Users simply select their target room from an intuitive dropdown and tap "Start Navigation" to begin.
Bridging Physical and Digital: This QR approach completely eliminates the need for expensive indoor GPS hardware or Bluetooth beacon installations.

Turn-by-Turn Directions

Contextual Awareness: A clear, high-contrast step counter (e.g., "Step 2 of 6") keeps users informed of their overall progress along the route.
Focused Directives: The interface isolates the immediate action required, highlighting critical turns so users don't have to parse a complex map while walking.
Synchronized Map State: As the user advances through the steps, the underlying map canvas updates its viewport to frame the current leg of the journey.
Paced Progression: Simple "Prev" and "Next" controls allow the user to advance the instructions at their own walking pace.
